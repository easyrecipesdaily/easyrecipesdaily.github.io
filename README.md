# Easy Recipes Daily

English-language static site for everyday home cooks: simple, tasty recipes for every day.

## Tools (vanilla JavaScript)
1. **Recipe Scaler** — scale ingredient quantities from original to desired servings.
2. **Ingredient Unit Converter** — cups ↔ grams (per-ingredient weights), oz ↔ g, lb ↔ kg, ml ↔ tbsp/tsp, °F ↔ °C.
3. **Calorie Estimator per serving** — total and per-serving calories from ingredient weights and kcal/100 g.
4. **Pantry Substitution Finder** — tested substitutes for 12 common missing ingredients.
5. **Meal Planner & grocery list builder** — pick dinners, set the number of people, get one combined grocery list.

## Content
- Reference tables: cups-to-grams weights for 10 common ingredients, plus oven temperature conversions (°F / °C / gas mark).
- 6 guide articles (weeknight dinners, scaling recipes, pantry staples, knife skills, meal prep, storing leftovers).
- FAQ section and an About/Disclaimer section.

Pure HTML/CSS/vanilla JS, no external libraries or webfonts. Deploy as a GitHub Pages user site at https://easyrecipesdaily.github.io/
